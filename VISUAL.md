# VISUAL.md — taste gate (agent eyes)

After `demos` screenshots (or looking at the live page), score each demo.

## Must-pass (★)

| Criterion | Pass | Fail |
| --- | --- | --- |
| ★ Hierarchy | Clear focal path | Everything same weight |
| ★ Spacing | Even gaps, air at edges | Collisions / cramped |
| ★ Alignment | Ranks/columns line up | Ragged |
| ★ Density | Slide sparse; system readable | Wallpaper or void |
| ★ Type | Labels wrap cleanly | Overflow / truncation storms |
| ★ Color | Theme + family chips | Rainbow / low contrast |
| ★ Depth | Light elevation | Flat PDF or glow spam |
| ★ Ground | Supports, doesn’t compete | Busy over labels |
| ★ Motion | Soft rise; story clear | Bounce / unclear replace |

Merge only when all ★ Pass for touched demos.
