What this deployment is 
ArcGIS Enterprise 12.3 on virtual machines, highly available, with ArcGIS Velocity for Enterprise.

Edge
  Web application firewall — client ingress. Sends traffic to the load balancer.
  External load balancer — organization URL and services URL, port 443.
Gateway
  Web tier between the two load balancers. With web-tier authentication this is
  ArcGIS Web Adaptor. Without it, the external load balancer can target Portal
  and Server directly.
Internal load balancer
  Private portal URL and the ArcGIS Server administrative URL. Server sites
  and the portal use this path to reach each other.

ArcGIS Enterprise 12.3 on VMs
  Portal for ArcGIS — primary and standby.
  Hosting GIS Server — two machines, one site.
  ArcGIS Velocity — one machine. Current Velocity docs support a single-machine
  site only. Processes on that machine: Control Plane, Feeds, Velocity Gateway
  (real-time messaging), Metrics, Real-time analytics, Stream Server.
  Velocity is federated with the portal and publishes through the hosting server.

Shared services
  File share on Nutanix Unified Storage — portal content directory, server
  configuration store, and server directories. The file server has to be highly
  available; otherwise it is a single point of failure for the portal and the
  server site.
  ArcGIS Data Store — relational primary and standby (required by the hosting
  server). Spatiotemporal big data store on its own machines for Velocity’s
  high-volume writes. Object store for the base deployment.
  Database as a Service — the registered enterprise geodatabase. User-managed
  data. It does not replace the relational data store.
