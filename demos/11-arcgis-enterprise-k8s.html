Kubernetes cluster
  arcgis namespace
    Framework pods — the architecture table: ingress, Help, Services API,
      Apps, notebook automation.
    Additional system deployments — private ingress, JavaScript API, Web styles,
      service lifecycle manager, usage metrics viewer, usage metrics data.
    Administration pods — Administrator API, ArcGIS Enterprise Manager,
      Organization (Portal), Portal (sharing) API.
    Service pods
      GIS services — feature, map, tile, image, geocode, geoprocessing, notebook.
        Shared GIS resources sit under GIS services: the shared-mode deployments
        for feature, map, tile, and image. Geocode, geoprocessing, and notebook
        do not run in shared mode.
      System services — PublishingTools; ReportingTools, SceneCachingControllers,
        and SceneCachingTools (started manually); RasterAnalysisTools,
        RasterProcessing, RasterProcessingGPU, and RasterRendering
        (started when raster analytics is enabled).
      Utility services — Printing (PrintingTools) and Geometry, both configured
        with the organization. Routing and GeoEnrichment are not configured
        by default.
    System storage
      Object store — mixed role on standard availability; metadata and data
        server roles on enhanced. Uploads, hosted tile and image caches,
        geoprocessing output. Cloud integration is supported.
      Relational store — primary and standby on every profile. Hosted feature
        data and configuration. Cloud integration is supported.
      Spatiotemporal and index store — mixed role on standard; coordinator and
        data roles on enhanced. Logs, indexes, and hosted feature data.
        No cloud service.
      Other StatefulSet volumes — queue store, in-memory cache, item packages,
        Prometheus. The three data stores above are StatefulSets as well.
  Availability profile — choose one when the organization is created:
    development and test, standard high availability (the default), or
    enhanced high availability.
  Outside the namespace — registered user-managed data stores, federated
    Windows and Linux sites, optional cloud object store, optional cloud
    relational store, and the World Geocoding Service on ArcGIS Online
    (the preconfigured locator).

Esri’s architecture diagram is an overview, not every pod in the cluster.
